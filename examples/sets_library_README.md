# Leo Explains Himself: biblioteca de decoruri

## Paleta comună
- Pereți: bej cald (#E8D9B8)
- Podea: parchet lemn deschis, tan/portocaliu moale
- Fereastră: ramă maro, cer albastru deschis
- Canapea / pătură pat: albastru-petrol (teal, #3A8FA3)
- Abajur / lustră: galben (#F2C230)
- Mobilă din lemn (masă, noptieră, ușă): maro
